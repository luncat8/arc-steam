# 0.3.3 — Infinite upper boundary

## Goal

Keep enough empty space above the ball for its damage radius by adding rows
smoothly before the top boundary is reached.

## Decisions

- Track the upper collapse boundary and the ball damage radius.
- If the ball would soon lack space above, add new rows.
- The damage radius must fit fully in the available area.
- Addition is smooth and capped at 5 rows per second.
- No sudden camera, object or ceiling shift.
- Combine with bounce-driven growth so the two sources do not conflict.

## Suggested implementation

- Add a boundary watcher in `js/ceiling.js`.
- Rate-limit row insertion with a timer.
- Share one insertion path with 0.3.2 growth.
- Add tests for cap, smoothing and conflict avoidance.

## Acceptance

- Rows are added before the radius leaves the view.
- Addition never exceeds 5 rows per second.
- No visual or physical jump.
