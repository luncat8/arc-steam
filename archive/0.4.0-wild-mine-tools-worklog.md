# 0.4.0 Wild Mine tools — worklog

## Rocket shard cave collision follow-up

- Fixed Wild Mine shard collision resolving the cave module factory as if it were the active cave instance. Wild Mine now reads `SteamWildMine.cave` and sweeps each shard step against that instance's SDF, allowing impacts on floors, walls, and overhangs instead of a vertical `floorBelow` approximation.
- Kept Classic shard collision and damage behavior unchanged. Wild impacts still apply the planned 5× fracture energy through the owner's damage multiplier and radius.
- Added a regression to `experiments/rocket-fab.test.js` that moves an actual shard into a cave surface and verifies that it is spent and causes fracture.
- Declared an empty data favicon so browsers do not probe for a missing default `/favicon.ico` asset (the reported 404 had no URL attached).

Validation: `node experiments/rocket-fab.test.js` (5/5), `node experiments/rockets.test.js` (17/17), `git diff --check`.
