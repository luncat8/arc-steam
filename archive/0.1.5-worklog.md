# 0.1.5 — Hit-point damage falloff, smooth heightmap reflection, full debris emission, and Space/Q shortcut fix

## Decisions and plan

- Fixed radial rock damage so each cell within the 4.5-cell (1.5×) radius receives `2 × impactJ × (1 - distance / 4.5)` strength removal (falling linearly from 2× at the hit point to zero at the radius edge) instead of dividing the budget by the sum of weights across all cells in the disk (which diluted hit-point damage by `~21.8×`). Booked fracture energy remains capped at `impactJ` so the energy balance stays exact.
- Kept the left-wall pocket so the asymmetric collector can dock into the wall and let the reflector cover `x = 0`, and removed the redundant triangular wedge block near the pocket from simulation, rendering, and documentation.
- Added rock shape modes with a smooth heightmap polyline as the default (`smooth`) and square cells (`square`) as an option. In smooth mode, column surface heights are smoothed into a continuous polyline used for both rendering and swept circle-versus-segment/vertex reflection. In square mode, swept collision tests only exposed cell faces and true rounded cell corners instead of expanded square boxes.
- Ensured broken cells are never lost on fracture and all broken mass falls: sized the debris pool to the full `192 × 16` cell count (`3072`), detached any lower cells in a column when a cell above them breaks, and added mass/value/mineral-preserving fragment aggregation if all pool slots are externally marked active.
- Fixed the `Space` shortcut so pressing `Space` (or `Q`) blurs any focused GUI control (`button`, `input`, `select`, `summary`) and prevents default on both `keydown` and `keyup`, preventing `Space` from re-pressing GUI buttons while supporting both `Space` and `Q` to toggle the bounce drive.

## Implementation

- `js/ceiling.js`: un-diluted 2× hit-point damage with linear falloff over `damageRadius = 4.5`; column detachment below broken cells; full-grid debris pool (`maxDebris = count`) plus fallback multi-cell fragment aggregation (`debrisCells`, `debrisValue`, `debrisMinerals`); smoothed column heightmap (`firstRow`, `heightmap`) and `setShape('smooth' | 'square')`; swept circle collision and angled normal reflection for both smooth heightmap and rounded-corner square cells; removed wedge debris bounce code.
- `js/physics.js`: removed wedge geometry and collision cases while retaining `pocketDepth` and `platformMin()` for the left-wall pocket.
- `index.html` / `styles.css` / `js/main.js`: added `#shape` selector (`Smooth heightmap` default, `Square cells` optional); removed wedge rendering; updated `keydown`/`keyup` to handle `Space` and `KeyQ` globally without activating focused GUI elements.
- `experiments/ceiling.test.js` / `experiments/physics.test.js` / `experiments/browser-smoke.cjs`: updated tests for hit-point linear falloff, multi-cell fracture without loss, smooth heightmap and square reflection normals, left-wall pocket without wedge, and `Space`/`Q` drive toggle when a GUI button was focused.
