## Review of the previous implementation

Read `0.3.6-Solubility-plan.md`, `solubility.2-plan.md`,

`experiments/solubility-geology-probe.cjs`, `js/minerals.js`,

previous worklog. Re-ran the 9 tests (9/9 pass). Added a deterministic probe
(`experiments/solubility-review-probe.cjs`) that measures each finding instead
of trusting the plan text.

Verdicts: F1/F2/F6-in-lab/F8 implemented; F3/F4/F5/F7 partial; live-game
integration (F5/F6 and parts of F3/F4) still pending per plan §8.2.

Load-bearing gaps found:

1. **Mode B vents Fluorite gas.** `model: 'formula'` at the Fluorite column
   produces 9.505 g / 116.25 cr lost gas and 0 g green brine, because
   `evaluateCellChemistry()` maps `out.gas` straight to `CHEM_GAS[9]`. Contradicts
   finding 3 and plan §1 item 7. Test 8 does not cover the LLH octant.
2. **Gas-rock stone residue is overpriced.** Residue uses the parent quote
   (`:366`), so 0.15 g of "Stone" is worth 22.50 cr instead of 0.435 cr; only
   127.50 cr of a 150 cr cell is booked as lost. GLM's corrected table asks for
   "debris at stone quote, gas gone".
3. **Static skeleton strength.** `remStrength` never falls with leaching and jet
   damage never enters the collapse gate (`:1211`), so 60/40 and 75/25
   Halite/Chalcopyrite seams (1.92 J / 1.20 J) never detach; the karst mixed seam
   yields 0 dissolved cells and 0 Copper clasts, contradicting finding 4 and the
   scene annotation. GLM's `strengthInto(remaining mix) - damage` coupling is
   missing.
4. **Mode B is not the published formula.** Extra normalisation, a leftover
   `reactTotal >= 0.22` gate, Gas center 0.802 vs plan ~0.61, Vitriol center
   0.907 vs plan's claimed 1.00 (old window 0.676, correct).
5. **Economy/calibration is prototype-only.** Quotes are literals, `js/minerals.js`
   has 10 rows with no `sol`/`rho`/`dye`, no `js/water.js`; lab geology scene uses
   a hybrid box set at `hostWeight 0.08` measuring `copper+vitriol = 8.30%`
   rather than the probe's calibrated 7.83%.
6. Smaller: `saturationFactor` 0.05 volume floor, proportional pump keeping
   `load/water` (and `sat`) constant, no hard capacity clamp, hardcoded jet
   `dt = 0.045`, `density` vs `rho`, a per-frame closure in `stepFluidGrid`, and
   plan statements that contradict the code (§4.2 line 120, §5 line 161, §6.2's
   75/25 example).

Full evidence, file/line references and prioritised P0–P3 fixes are in
`0.3.6-Solubility-implementation-review.md`.
