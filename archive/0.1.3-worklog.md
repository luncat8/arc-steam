# 0.1.3 — 2D rock, cargo mass, and wall sales

## Decisions and plan

- Resolved the mining-loop storage and sale rules in the standalone plan: 100 cells, 0.6 kg per cell, full cargo equal to the 60 kg dry platform, and automatic whole-load sale at either side wall.
- Fixed the default rock simulation grid at 192 × 16 cells over 24 m × 2 m. A 0.125 m cell is approximately 4 × 4 px at the reference canvas scale; responsive rendering does not alter physical resolution or yield.
- Defined four rock views: elemental R/G/B, mineral composition, price, and remaining strength.

## Implementation

- Replaced the one-row ceiling with seeded two-dimensional element and mineral fields, per-cell strength/value, 2D radial damage, and bounded fragment storage.
- Added swept circle-versus-cell queries. Balls now contact exposed intact cell faces and reflect along the returned face normal; excavated cells expose deeper and side faces.
- Added selectable rock rendering for all four requested views.
- Added a 100-cell cargo limit, cargo/funds/platform-mass telemetry, and vertical `SELL` labels at both walls. Wall contact sells stored material automatically.
- Made each cargo cell contribute 0.6 kg to force-limited movement and braking. Fragment capture merges horizontal momentum with the loaded platform and converts collision losses to heat.
- Extended the energy ledger across attached-rock potential, active debris, carried cargo, sales exports, and fragment capture/loss. Float64 moving-fragment state keeps accounting drift below the existing numerical tolerance.
- Updated current-scope documentation and mining-loop acceptance criteria.

## Validation

- `node --test experiments/*.test.js`: 17/17 pass. New coverage checks 2D deterministic fields, normalized element/mineral weights, 2D damage, swept exposed-face contact, hard storage capacity, full-load mass, capture momentum/energy, cargo-dependent acceleration, and wall sale accounting.
- `node --check js/ceiling.js`, `node --check js/physics.js`, `node --check js/main.js`, and `git diff --check`: pass.
- Browser smoke was not run because no browser executable is installed in this environment; no browser validation is claimed.

## Next step

Tune cell strength, yield, and prices through measured mine–collect–sell trips, then add the first equipment purchase comparison so earned funds have an operational use.
