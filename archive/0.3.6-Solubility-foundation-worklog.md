# 0.3.6 Solubility — P1 cleanup and P2 mineral/economy foundation

## Scope and review

Reviewed the P0 implementation and its worklog before editing. The exclusive
bound-B channels, stone-quoted gas residue, dynamic seam collapse and calibrated
boxes are retained. The next integration dependency was the duplicate lab table:
it carried its own quotes, while the live game still formed only ten minerals.
The fixed gold value percentage would also be wrong for a different market.

This milestone completes the shared mineral/economy foundation and the cheap P1
buffer/closure cleanup. It does **not** complete the live-water milestone:
`js/water.js`, water equipment/controls/settings persistence, the live gas HUD,
`experiments/water.test.js` and `water-yield-probe.cjs` remain unimplemented.

## Changes

1. **Canonical definitions (`js/minerals.js`).** Thirteen forming minerals plus
   liberated `pure_gold` (`gen: false`), using plan §4.2's calibrated boxes.
   Added shared chemistry/density/dye/reaction properties and explicit calibrated
   targets; Copper + Vitriol target totals 7.83%. The game and solubility lab use
   the same physical definitions and shared geology defaults (`hostWeight =
   0.0883`). Lab-only octant labels and representative RGB values remain
   presentation metadata. Indices now follow the solubility table; exports remain
   keyed by stable mineral IDs.
2. **Non-forming phase handling.** Geology excludes Pure Gold from affinity,
   range separation, calibration errors and range-width adjustment. The mineral
   editor disables its desired-share/range controls and does not warn that it is
   absent. Synthetic test rock may still contain a pure sample of it.
3. **One economy path.** `basePricesInto()` excludes liberated phases from the
   abundance-price normalisation and derives Pure Gold from Gold-quartz minus
   75% Quartz gangue. The live market uses the same derivation on every update;
   its quote may exceed the ore cap. Non-forming phases do not stretch the rock
   price-view ramp.
4. **Lab pricing.** Default reference quotes come from `basePricesInto()` on
   calibrated target shares, not copied literals. `createSimulation({ prices })`
   copies a supplied quote vector before creating the scene; rock, brine,
   gas-residue repricing and grain tools all read that simulation's snapshot.
   Existing brine/debris stays booked at its acquisition value. Pure Gold is
   re-derived from the snapshot rather than trusting a separately supplied quote.
   Quote-driven residue transformations cannot increase the parent's unit value.
5. **Market-exact placer split.** Gangue takes `quartzMass * quartzQuote`, and
   the nugget takes exactly the remaining value. No hardcoded 97.35% coefficient.
   If gangue alone would exceed the original value, liberation waits; grain
   physics continues without minting value or producing negative-price gold.
6. **P1 allocation cleanup.** Hoisted the fluid transfer helper out of the
   per-step closure, the mixed-rubble selection list and karst label arrays out
   of recurring paths. Added `createMetrics()` and caller-owned output to
   `measureMetrics(state, out)`; the HUD reuses both accumulator arrays and its
   result object. The default measurement call still returns independent
   snapshots for probes/tests. This is buffer-allocation cleanup, not a claim
   that all changing render/HUD text is allocation-free.
7. **Tests/probes/spec.** Added seven integration tests, replaced the mirrored
   calibration solver with the live geology API, and refreshed the review probe.
   Corrected the plan's Gold pricing rule and documented integration boundaries;
   kept the historical review explicitly marked as a pre-P0 snapshot.
