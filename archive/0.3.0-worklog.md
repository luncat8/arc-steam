# 0.3.0 — Platform render stabilization

- Reviewed the previous platform implementation and found separate styling
  paths, a non-dimmed accent outline and stale colour caches.
- Replaced `drawBody` with `renderPlatform(context, player, rigMachinery, isActive)`.
- Both platforms now use one model, one size set, one shape set and one
  transform; only alpha changes with activity.
- Removed the bounding-box outline from normal rendering.
- Dim is computed every frame from `players.active`; no dimmed colour is stored.
- Moved dim application inside `renderPlatform`, so switching players moves it
  immediately and repeated switching cannot accumulate.
- Exposed `renderPlatform` from `SteamPlayers`.
- Created English plans `0.3.0-plan.md` through `0.3.7-plan.md` for the
  planned ceiling, rock growth, rockets, sandblaster and balance work.

- `git diff --check` — clean.
