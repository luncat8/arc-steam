# 0.3.4 — Perspective scaling of the ball

## Goal

Add a setting that shrinks the ball in the distance using the same law as
rock cells.

## Decisions

- Checkbox in settings toggles the effect.
- Off: ball size stays constant.
- On: the ball shrinks upward according to the rock cell scale law.
- By default only the visual size changes; physics radius and damage balance
  stay unchanged.
- The damage radius must still be represented correctly when the effect is on.

## Suggested implementation

- Add a setting flag and UI checkbox.
- Apply the scale in the ball render path only.
- Keep collision and damage radii unscaled.
- Persist and load the flag.
- Add tests for toggle and visual-only behaviour.

## Acceptance

- Toggle changes only rendering.
- Physics and balance are unchanged.
- Damage radius indication stays correct.
