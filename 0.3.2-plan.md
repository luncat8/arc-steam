# 0.3.2 — Top rock growth

## Goal

The rock ceiling grows downward from the top: one new row is added on every
ball bounce, so the playable space is replenished from above.

## Decisions

- Each bounce creates exactly one new rock row at the top.
- The new row enters smoothly instead of popping in.
- Existing world content shifts down consistently.
- Physics coordinates, camera and the visual grid stay synchronized.
- Mineral generation in new rows follows the current depth rules.

## Suggested implementation

- Add a top-row insertion queue in `js/ceiling.js`.
- Animate insertion with a fractional row offset.
- Update camera and world offsets together with the shift.
- Generate minerals for the new row using the existing noise/depth logic.
- Add tests for row count, ordering and coordinate consistency.

## Acceptance

- One bounce adds one top row.
- No jump in camera, objects or ceiling.
- Physics and rendering remain aligned.
